# UI全面書き直し

## 概要

`.workspace`のデザイン仕様書、ワイヤーフレーム、コンポーネント実装を正本として、公開UIを全面的に書き直しました。
採用構成はワイヤー `6b + 5a + 4a`で、375pxのモバイル操作とPCレイアウトを同じ設計tokenから実装しています。
データ契約を変更せず、表示整形、同意状態、派生artifact、loading／empty／errorの状態を公開contractに従って出し分けます。
実測による設計適合、browser E2E、backend検証、aggregate検証の結果をこのPRに添付します。

## 変更の内訳

- design token、AppShell、`components/ui/`の14 componentを実装しました。
- 全8 pageを、採用ワイヤーの画面構成・状態・responsive要件へ合わせて移植しました。
- `lib/format.ts`を追加し、投稿日、長さ、件数、日時、派生情報の表示形式を集約しました。
- デザイン正本を移植・更新し、視覚40px／hit領域44pxのsidebar仕様を明記しました。

## 実測で検出して修正した不適合

- 投稿日 `2026-06-30T22:10:00Z` と長さ `PT2H30M20S` が生値のまま表示されていた → `lib/format.ts`へ表示整形を集約し、日本語の日付と読みやすい長さへ変換しました。
- error画面が `failed to load /data/latest.json: HTTP 503` という英語技術文字列をそのまま表示していた → retryable errorとして日本語の利用者向け説明・詳細・再取得操作へ分類しました。
- 未同意詳細でリンクが重なり、未同意にもかかわらず同意取り下げ操作が出ていた → 未同意時は同意・規約導線のみとし、YouTube導線、派生情報、取り下げ操作を同意後だけに表示しました。
- skip linkが43.80px、footer linkが22.09pxで、44pxのhit領域要件を満たしていなかった → 両リンクへ最小44pxの操作領域を与えました。
- sidebar項目の40pxと44px要件が矛盾していた → 視覚背景を40px、Linkのhit領域を44px以上へ分離し、正本にも明記しました。
- `artifactFlags.chat=false`の動画にチャット数を表示していた → chat flagがtrueで、かつ実在する集計値があるときだけ表示するようにしました。

## 設計判断

- 外部CDN・webfontは使いません。`docs/spec/22.system-specifications.md`のCSP要件に合わせ、実際に必要なstatic assetとYouTube導線だけをallowlistできる構成を保つためです。
- アイコンはinline SVGで自作しました。外部icon取得を避け、CSPと画面の表示決定性を保ちます。
- カレンダーは依存を追加せずARIA gridとして実装しました。開始→終了の2タップ、日付のキーボード操作、`aria-selected`、Escで条件へ戻る要件を実装しています。

## 仕様どおりにできていない箇所

一覧のcaptionにチャット数は出ません。release indexには`chat.totalCount`がなく、per-video詳細JSONにしか存在しないためです。欠落値を捏造しない方針により表示していません。表示するにはexport側がindexへ総数を含める変更が必要です。

## 既知の環境依存

WSL2ではPlaywrightの既定並列workerがexit code 144でkillされることがありました。このため`playwright.config.ts`の既定workerを1にしました。安定した環境では`PLAYWRIGHT_WORKERS`で上書きできます。
