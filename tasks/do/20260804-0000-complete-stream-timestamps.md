# 白雪巴出演アーカイブのタイムスタンプ完全化

状態: 実施中

## 目的

添付された`target_videos_v1.tsv`を追跡台帳の初期集合とし、既存の移植済みタイムスタンプ、除外対象、未作成対象を動画単位で判定する。未作成かつ除外対象でない配信アーカイブは、添付されたタイムスタンプ生成skillの品質gateを満たす章立てを作成し、公開releaseと追跡台帳へ反映する。

## 対象

- TSVの1,800本
- 既存release `20260729-001`でタイムスタンプ移植済みの1,206本
- TSVにあり既存releaseにない594本
- 2026-08-04時点でTSVに未収載の白雪巴本人チャンネル配信アーカイブ
- 2026-08-04時点でTSVに未収載の他チャンネル出演配信アーカイブ

## 対象外

- Shorts、歌ってみた／cover、収録MVなど、章による長尺アーカイブ内移動が利用価値を持たない動画
- 非公開、削除、年齢・地域・会員制限などにより全編の字幕または音声を取得できず、入力品質gateを満たせない動画
- YouTubeへの章投稿、production deploy

## 受け入れ条件

- [ ] 追跡台帳に対象動画を1行ずつ記録し、動画ID、タイトル、チャンネル、公開日時、長さ、作成済み、除外対象、除外理由、処理状態、commitを持つ。
- [ ] 既存releaseにタイムスタンプがあるTSV動画1,206本を作成済みとして記録する。
- [ ] 除外対象は動画形式と長さの根拠を記録し、未作成と混同しない。
- [ ] 未作成かつ除外対象でない全動画について、連続する全編字幕またはASR、根拠付き境界、独立した事実・編集レビュー、決定的validatorを通す。
- [ ] 動画ごとに公開データ、検証、追跡台帳を更新し、目的単位のcommitをpushする。
- [ ] 本人チャンネルと他チャンネル出演アーカイブの追加分を調査し、同じ判定・生成・検証を適用する。
- [ ] 公開release、検索index、契約、frontend表示の回帰検証を実施し、未実行・blockedをpassと記録しない。
- [ ] 最終差分と検証結果をPR #3へ反映する。重複PRは作らない。

## 主要リスクと対応

| リスク | 影響 | 対応 |
| --- | --- | --- |
| 字幕・音声の取得不能 | 内容を推測した誤章立て | `blocked_input`として記録し、作成済みにしない |
| ゲーム・TRPGのネタバレ | 公開章名が視聴体験を損なう | 内部題と公開題を分離し、独立編集レビューを行う |
| 1,800行と大量JSONの更新 | 対象漏れ・重複 | videoIdの集合差、件数、重複0件を自動検査する |
| 既存PR #3との重複 | reviewとmergeの混乱 | 既存branchへfast-forward commitを追加しPR #3を更新する |

### 現在のblocker

1. YouTubeへの追加取得が実行環境のネットワーク許可で停止し、残り244本の字幕監査を完了できない。
2. 字幕なし80本は全編ASRが必要だが、archive全体に対するASR実行資源がない。
3. 年齢制限37本とメンバー限定2本は、認証済みの字幕または音声入力がない。
4. ZIPのworker契約が要求する `gpt-5.6-luna` がこの実行環境で選択不能で、意味マッピング以降の品質gateを開始できない。

上記を解消するまで動画を作成済みにはせず、台帳では `入力待ち` または `作業中` として保持する。PR #3は既存のopen PRを継続利用し、重複PRは作成しない。

### 2026-08-04 yt-dlp再検証

- 利用者から`gpt-5.6-sol`利用の許可を得た。モデル名の固定は解除されたが、事実レビューと編集レビューを独立した新規contextで行う品質gateは引き続き必要である。
- `yt-dlp 2026.07.04`を隔離venvへ導入し、通常公開・字幕なし・年齢制限の3種で実測した。
- `UZcmZzKQWYc`は`ja-orig` VTTを取得できた。実体は644,441 bytes、SHA-256は`46898109f6b9b7113b0e268e32e57b3ec7ddf955746b01f452e3ce609c5e53a9`、正規化後1,493 cue、raw timingは119.079〜5,113.159秒、10秒以上のtiming gapは0件だった。
- 字幕なしの`ajB1VeIsrlc`は音声formatと署名付きURLの解決まで成功したが、実ダウンロードはメディアCDNから195 bytesの`Site Unavailable` HTMLが返った。`yt-dlp`の終了コードは0だったため、終了コードだけで入力取得成功と判定してはならない。
- 年齢制限の`gl5UkwS_jmM`は未認証では`Sign in to confirm your age`となり、字幕・音声とも取得不能だった。ブラウザCookieまたは利用者提供の全編入力が必要である。
- Google Sheets台帳では上記3本の状態と根拠を更新した。`UZcmZzKQWYc`のみ`処理中`、残り2本は`入力待ち`を維持した。

### 更新後のblocker

1. 公開字幕は`yt-dlp`で取得できるため、字幕あり動画の入力監査は再開可能である。
2. 字幕なし動画は`googlevideo.com`の実メディア取得が環境で遮断され、全編ASRへ渡す音声を保存できない。ダウンロード成功判定には、非HTML、妥当なサイズ、ffprobeでの再生時間一致を必須とする。
3. 年齢制限37本とメンバー限定2本は、認証済みCookieまたは利用者提供の字幕・音声が必要である。
4. `UZcmZzKQWYc`は章候補の意味マッピングまで進められるが、独立した事実・編集レビューと決定的validatorを通るまでは公開releaseへ入れない。
