## 採用構成: 検索フロー（4a）

### 1. 検索入力中

検索画面の先頭に検索バー（h44、radius14）を置く。キーワード・タグ・話し言葉を入力し、入力中だけ直下にサジェストを表示する。サジェストは最大4行、内訳はタグ2件以下（件数降順）、日付解釈1件以下、入力語のまま検索1件。各行h44で、タグは部分一致と同義語（例: 「うた」→「歌枠」）から出し、件数を添える。

- タグ候補を選ぶ: 入力語をタグトークンにし、結果条件へ追加する。
- 日付候補を選ぶ: 日付条件へ追加する。
- キーワード行を選ぶ: 未確定語をそのまま検索する。
- 入力フォーカスを失うとサジェストを閉じる。解釈プレビュー枠は置かない。

### 2. 検索結果

上から検索バー（タグトークン+キーワード）、**sticky条件行**、件数と並び順、動画リストを並べる。条件は入力欄内トークンと条件行だけに集約し、スライダー・カレンダー・全タグ一覧は本文に出さない。

条件ゼロでは `＋タグ / ＋長さ / ＋投稿日` の破線チップを常設する。条件ありでは同じ位置を removable chip（例: 期間、1〜3.5h）と `条件 (n)` アクションチップへ置換する。removable chip本体は該当シート節へ移動し、closeは当該条件だけ即時解除する。条件行は横スクロール、折返しなしでスクロール後も固定する。

動画リストは行間12px。各行はサムネイル96×54（ワイヤー）を左、タイトル・日付・長さ・集計済みチャット数を右に置く。詳細コンポーネント仕様のtargetではサムネイル120×68に正規化する。

### 3. 条件シート（mobile）／右パネル（PC）

`条件 (n)`、追加チップ、removable chip本体から開く。mobileは背景オーバーレイ上の下からのシート（上部radius20、ハンドル36×4）、背景タップ・下スワイプ・Escで閉じる。PCは同じ内容を右からスライドするw320パネルで表示する。開く契機が `＋長さ` 等なら該当節へ自動スクロール・ハイライトする。

内容は常に次の3節を縦積みする。

1. タグ: 複数選択チップと `すべて` の入口。
2. 長さ: 下限・上限の2つまみレンジ。0、1h、2h、3h、4h、5h+を表示し、選択値は例として `1h〜3h30m`。
3. 投稿日: `3ヶ月以内`、`今年`、カレンダー入口。選択値を節見出しに表示する。

最下部は固定CTA（例: `18件を表示`）で、条件変更ごとに件数をライブ更新する。0件では `0件 — 条件をゆるめる` と直近条件を外す提案を表示する。

### 4. カレンダー差し替え状態

カレンダーは別画面・全画面に遷移せず、シート内を差し替える。ヘッダーは「条件に戻る／投稿日／クリア」、月移動の前後ボタン、曜日行、7列グリッド、選択範囲表示、固定CTAで構成する。開始日→終了日の2タップで範囲を確定し、範囲内はprimary-100、端点はprimary-500の円形表示、配信がある日はドット、未来日はdisabledとする。視覚セル40×40だがヒット領域は44px以上。

## 画面別ワイヤー

### ホーム

mobileは検索バーを最上部に置き、検索ファーストのリストカードを主とする。クイックタグを介して検索へ入る。PCはサイドバーと、動画グリッド（3〜4列）またはリストを用途に応じて使う。empty時も検索・追加条件の入口を消さない。

### 保存・履歴

同じ動画リスト行を使う。保存はユーザーが保存した動画、履歴は閲覧済み動画を表示する。空状態は理由と次の行動（検索へ）を示し、ナビ・検索導線は維持する。

### 動画詳細

mobileはサムネイル、タイトル、メタ、タグ、YouTube CTA、保存操作、派生情報の順。PCでは本文幅を制限し関連動画をグリッドで補助できる。未同意時は同意・規約導線を先に示し、同意後のみYouTube導線・派生表示を有効にする。派生artifact未作成は0件に偽装せず「未作成」と区別する。

### 読み込み・空・エラー・未検出（loading / empty / error / not found）

- loading: コンテンツ位置を保つストライププレースホルダー。読み込み状態をprogrammaticに伝える。
- empty: 件数0と条件緩和提案を表示する。ただし公開artifact欠落を0件とは表示しない。
- retryable error: 理由、詳細、再取得ボタン。フォーカスを奪わない。
- permanent / policy error: 利用不可理由と安全な代替導線のみを示す。
- not found: ページ不存在を本文見出しとして表示し、ナビは維持する。

## 遷移・モーション・a11y

シート／パネルは240ms ease-out、サジェスト開閉120ms、チップと件数更新は即時。`prefers-reduced-motion` では非本質的な移動を無効化する。シートはfocus trap、Esc閉じ、close後は開いたトリガーへfocus returnする。選択件数はpolite live regionでまとめて通知し、色だけで選択・disabled・エラーを伝えない。
